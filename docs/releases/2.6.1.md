# bazis-users 2.6.1

Requires Bazis 2.6.

## Fixes

- **A project can no longer miss the login silently.** The token endpoint
  (`POST BAZIS_OPENAPI_TOKEN_URL`) is a route of the application, declared when its module
  is imported, and only `bazis.contrib.users.routes` declared it: a project that routes the
  users itself (with bazis-permit) and does not register `bazis.contrib.users.router` had
  no login, while every route still pointed Swagger and the clients at the token URL. The
  endpoint now has its own module, `bazis.contrib.users.token`, which the router module of
  the project imports (`bazis.contrib.users.routes`, and so the user routes, still import
  it: nothing changes for the projects that register them). The new system check
  `users.E002` (run by `manage.py bazis_doctor`, with the application loaded) reports a
  project without the endpoint. The guide describes the import as a setup step.
