# bazis-users 2.10.1

## Fixes

- **A full `save()` of a user with a language the project no longer has answered 422 when
  the language was deferred and loaded with the other users (Django 6.1, `FETCH_PEERS`).**
  `UserLanguageMixin` validates the language on save only when it is written and changed,
  comparing it with the stored one it remembers at `from_db` and `refresh_from_db`.
  `FETCH_PEERS` sets the deferred value without `refresh_from_db`, so the stored language
  stayed unknown and the unchanged stale code (`LANGUAGES` without it) was checked as a
  new one: `for u in User.objects.defer('language').fetch_mode(FETCH_PEERS): u.language;
  u.save()`. When the stored language is unknown at a save of a written language, it is
  now read from the database once.
