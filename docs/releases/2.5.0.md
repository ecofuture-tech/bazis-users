# bazis-users 2.5.0

Requires Bazis 2.5.

## Breaking changes

- **The package no longer defaults `AUTH_USER_MODEL` to `users.User`.** The settings of
  every installed Bazis package are loaded in every project, so the default made Django
  fail at startup in projects that have bazis-users installed but do not use the users app.
  Bazis 2.5 declares `AUTH_USER_MODEL` with the default of Django; a project with the users
  app sets `BS_AUTH_USER_MODEL=users.User` (or its own user model).

## Tools and AI agents

- `users.E001` tells exactly what to add when `AUTH_USER_MODEL` is still Django's
  `auth.User`: `BS_AUTH_USER_MODEL=users.User`.
