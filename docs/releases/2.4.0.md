# bazis-users 2.4.0

Requires Bazis 2.4.

## Security

- **Any authenticated user could take over any account through the user routes**
  (`bazis.contrib.users.router`, `UserRouteSet`): list all users, change any user,
  including his password (`raw_password`) and `is_staff` / `is_superuser`, and delete
  users. Now a user who is not staff sees and changes only himself; only staff create and
  delete users; only a superuser changes `is_staff`, `is_superuser` and `is_active`
  (403 otherwise). Projects that let users manage other users through these routes must
  give them staff status.

## Tools and AI agents

- The package ships `AGENTS.md` (how to set up users and authentication) and
  `bazis_manifest.toml` for tools and AI agents (see `docs/agents.md` of Bazis).
- New system check `users.E001`: the user model does not inherit `UserAbstract`
  (`manage.py bazis_doctor`).
